# Proyecto Integrador: Semáforo

## Descripción del proyecto
El proyecto consiste en crear un semáforo utilizando Arduino.
El sistema tendrá tres luces LED: roja, amarilla y verde.
Las luces se encenderán y apagarán automáticamente
en una secuencia para representar el funcionamiento
de un semáforo de tránsito.

## Objetivo
Construir y simular un semáforo que funcione automáticamente
utilizando Arduino y la plataforma Wokwi.
